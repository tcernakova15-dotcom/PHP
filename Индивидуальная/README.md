# GameVault — Каталог и магазин компьютерных игр (PHP + PDO)

## Описание лабораторной работы
Индивидуальная работа по дисциплине «Веб-программирование на стороне сервера (PHP)». Разработано модульное веб-приложение **GameVault** для просмотра, поиска, добавления и покупки компьютерных игр с разграничением прав доступа (гость, авторизованный пользователь, администратор).

### Требования
* PHP 8.1 или выше (с включённым расширением `pdo_mysql`)
* MySQL 8.0+ или MariaDB 10.6+ (либо Docker Desktop)
